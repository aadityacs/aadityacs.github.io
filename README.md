# aadityacs.github.io

Edit a file on GitHub, commit, and the site rebuilds in a few minutes.

| Change | File |
| --- | --- |
| Bio, address | `_pages/about.md` |
| Papers | `_bibliography/papers.bib` |
| Patents | `_bibliography/patents.bib` |
| Paper images | `assets/img/publication_preview/` |
| Photo | `assets/img/prof_pic.jpg` |
| CV | `assets/pdf/CV_Aaditya_Chandrasekhar.pdf` |
| Email, Scholar, GitHub, LinkedIn | `_data/socials.yml` |
| News | new file `_news/2027-01-15-title.md` |

A news file looks like this. The first time, set `announcements: enabled: true` in `_pages/about.md`.

```markdown
---
date: 2027-01-15
inline: true
---
Our paper on X is out in SMO.
```
